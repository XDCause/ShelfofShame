Keeping this map current

Everything listed above comes from one data block at the bottom of docs/stack.html. When something is added, it goes there too:

  1. A new API module, hobby or script: add it to the data. api/tests/test_docs.py fails until every module in api/app, every hobby in web/src/modules and every .ps1 script is on this map.
  2. A new outside site: add it to sites and to the parts that use it (and a stand-in, and a row in BEFORE_GOING_PUBLIC.md).
  3. A new tool or a version change: update its line in tools (check-updates.ps1 lists what's newer).
  4. A change to how requests travel: redraw the diagram (the SVG near the top).
